WaveMaker 11.16.2 upgrades Node.js to 22.23.4 and npm to 10.9.9 for building Angular and React Native apps.

## Enhancements

<details><summary>Node.js and npm Upgrade (Web and Mobile)</summary>

Building Angular and React Native apps now requires Node.js 22.23.4 and npm 10.9.9, so upgrade both in your local and CI/CD build environments.

For the exact versions, see the [Technology Stack](#technology-stack) section of these release notes.

</details>
