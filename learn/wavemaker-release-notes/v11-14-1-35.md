WaveMaker 11.14.1.35 is a runtime patch for WaveMaker 11.14.1 that fixes security vulnerabilities in React Native apps by upgrading the `handlebars` dependency.

## Bug Fixes

### React Native

<details>
<summary>Security Vulnerabilities Fixed</summary>

Fixed security vulnerabilities by upgrading the `handlebars` dependency from 4.7.7 to 4.7.10.

</details>
