WaveMaker 11.14.1.34 is a runtime patch for WaveMaker 11.14.1 that fixes security vulnerabilities in React Native apps and accessibility issues in web apps.

## Bug Fixes

### React Native

<details>
<summary>Security Vulnerabilities Fixed</summary>

Fixed security vulnerabilities in the runtime dependencies. The Expo and React Native versions are unchanged.

</details>

### Web

<details>
<summary>Accessibility Issues in Breadcrumb, Search, Table Action and Form Field</summary>

Fixed accessibility issues in the Breadcrumb, Search, Table action and Form Field widgets in web apps.

</details>
