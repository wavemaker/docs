WaveMaker 11.14.1.34 is a runtime patch for WaveMaker 11.14.1 that fixes security vulnerabilities in third-party dependencies of React Native apps and accessibility issues in web apps.

## Bug Fixes

### React Native

<details>
<summary>Security Vulnerabilities Fixed in Third-Party Dependencies</summary>

Fixed security vulnerabilities in the following third-party dependencies. The Expo and React Native versions are unchanged.

- `image-size`: updated to 0.6.2 and 0.5.5.
- `inflight`: replaced with `inflight-lru` 1.0.0.
- `lodash-es`: updated to 4.18.1.
- `moment`: updated to 2.31.0.
- `debug`: updated to 4.4.3.

</details>

### Web

<details>
<summary>Accessibility Issues in Breadcrumb, Search, Table Action and Form Field</summary>

Fixed accessibility issues in the Breadcrumb, Search, Table action and Form Field widgets in web apps.

</details>
