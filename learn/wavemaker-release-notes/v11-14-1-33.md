WaveMaker 11.14.1.33 is a runtime patch for WaveMaker 11.14.1 that adds pull-to-refresh for page content and support for the blur effect on widget background images, and fixes the Dialog widget's `modal` property behaving in reverse on mobile , read-only Form Fields being editable at runtime, and the Bottom Sheet detaching from the bottom of the screen on Android.

## Features

### React Native

<details>
<summary>Pull-to-Refresh for Page Content</summary>

Users can now pull down on page content to refresh the page without navigating away and back. The refresh reloads startup variables and actions on the page, including those in child prefabs and partials, and shows a loading indicator until they all finish. Pull-to-refresh is disabled when the device is offline.

</details>

## Enhancements

### React Native

<details>
<summary>Blur Effect Not Supported on Background Images</summary>

Fixed background images always rendering sharp. You can now blur a widget's background image with the `backdrop-filter` style property, for example `backdrop-filter: blur(10px)`. The blur value ranges from 0 to 100; values outside this range are clamped to it, and a missing or invalid value renders the image without blur. The blur applies only to the background image, not to the widget's content.

</details>

## Bug Fixes

### React Native

<details>
<summary>Dialog Modal Property Behaving in Reverse on Mobile</summary>

Fixed the Dialog widget's `modal` property working the opposite way on mobile. When `modal` is true, tapping outside the dialog no longer closes it and the user must use the close button; when `modal` is false (default), tapping outside closes it, matching the documented and web behavior.

</details>

<details>
<summary>Read-Only Form Field Editable at Runtime</summary>

Fixed Form Fields marked as read-only still being editable at runtime because the form's insert/edit mode overrode the field's read-only setting. A Form Field with `readonly` set to true now stays non-editable at all times, whatever the form's mode, for all field types. Fields without `readonly` set still follow the form's mode as before.

</details>

<details>
<summary>Bottom Sheet Detaching from Bottom of Screen on Android</summary>

Fixed the Bottom Sheet detaching from the bottom of the screen on Android after tapping the search icon inside it, and then moving upward on tap to reveal the content underneath. The Bottom Sheet now stays anchored to the bottom when the keyboard opens and closes. iOS was not affected.

</details>
