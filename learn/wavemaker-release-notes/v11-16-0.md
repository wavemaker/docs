WaveMaker 11.16.0 upgrades generated Angular apps and WaveMaker Studio to Angular 22, and React Native apps to Expo SDK 57.
This release also includes enhancements to Data Table, REST API import, and OpenID security configuration, along with several bug fixes across Studio and Web.

## Features

<details><summary>Expo SDK 57 upgrade (React Native)</summary>
React Native apps now use Expo SDK 57, keeping apps aligned with the latest Expo release. For the exact versions, see the [Technology Stack](#technology-stack) section of these release notes. For more information, see the [Expo SDK 57 changelog](https://expo.dev/changelog/sdk-57).
</details>

## Enhancements

<details><summary>Bind Support for Data Table Advanced Settings</summary>
Properties in the Data Table advanced settings dialog now accept bind expressions.
</details>

<details><summary>Support for Multiple and Optional Query Parameters</summary>

- REST API import now supports multiple values for the same query parameter.

  **Example:** `?category=books&category=electronics`

- Query parameter values can now be left empty during import and bound later when creating variables or configuring API orchestration.

</details>

<details><summary>Client Authentication Method for OpenID Providers</summary>
Adds a **Client Authentication Method** property to OpenID security provider configuration in Studio.
</details>

<details><summary>Angular 22 and Frontend Library Upgrades</summary>

Generated Angular apps move from Angular 18 to Angular 22, keeping apps aligned with the latest framework release. ngx-bootstrap has been updated to its matching major version. WaveMaker Studio itself has also been upgraded from Angular 18 to Angular 22.

:::warning
**Action Required: Node.js upgrade**

Node.js for Angular apps is updated from 22.18.0 to 22.22.3. Upgrade Node.js to 22.22.3 in your local and CI/CD build environments before building Angular apps.
:::

For the exact versions, see the [Technology Stack](#technology-stack) section of these release notes.

</details>

## Bug Fixes

<details><summary>Chips Widget Bound Values in Live Form View Mode</summary> Fixed the Chips widget not displaying bound values correctly in a Live Form in view mode. </details>

<details><summary>Tabs Inside a Dialog Show a Blank Screen</summary> Fixed a Tabs widget placed inside a Dialog rendering a blank screen. </details>

<details><summary>Focus Lost When Switching Between Tables</summary> Fixed input focus being lost when moving between Data Tables. </details>

<details><summary>All Inner Tabs Shown in Form Edit Mode</summary> Fixed every inner tab inside a form being displayed at once in edit mode. </details>

<details><summary>Invalid State on Initial Form Load</summary> Fixed form fields getting the `ng-invalid` class before any user input. </details>

<details><summary>Main Page Layout Breaks After Switching From a Partial Dialog</summary> Fixed the Main page canvas rendering a distorted layout after switching from a Dialog component opened in a Partial page in Studio. </details>

<details><summary>Hidden Components in a Dialog Appear After Switching Pages</summary> Fixed an issue where components inside a Dialog with the **Show** property set to `false` became visible on the canvas after switching pages and returning to the original page in Studio, even when **Show Hidden Elements** was disabled. These components now remain hidden across page switches. </details>

<details><summary>Prefab Publish API Not Working on Version Conflict</summary> Fixed the `/prefabs?forceRegister=true` API not being invoked while importing or publishing a prefab to a project. Previously, a "Prefab Version Mismatch" dialog appeared with a continuous spinner (non-responsive) and console errors were thrown. </details>

<details><summary>Server-Side Pagination Not Working for a Table in a Partial</summary> Fixed server-side pagination not working for a table in a partial when its dataset is bound to `App.activePage.Variables.VariableName.dataSet`. </details>

<details><summary>Invalid Class Added for a Valid Date on a Form Field</summary> Fixed the invalid class being intermittently attached to the Date input widget or form field even when the entered date was valid. </details>

<details><summary>Filter Displays All Values Instead of Filtering Based on the Selected Value</summary> Fixed the DataTable Multi-Column Filter displaying all values instead of filtering based on the selected value (for example, the selected City). </details>
