WaveMaker 11.14.1.31 is a runtime patch for WaveMaker 11.14.1 that improves the reliability of session sharing between the mobile app and an external website via the shared system browser.

## Enhancements

### React Native

<details>
<summary>Reliable Session Sharing via Shared System Browser</summary>
Improves the reliability of session sharing between the app and an external website by reusing the IdP session through the shared system browser (Custom Tabs on Android, ASWebAuthenticationSession on iOS). Set `authMode: "auth_session"` in `browserConfig` to enable this behavior.
</details>
